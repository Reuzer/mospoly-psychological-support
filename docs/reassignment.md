# Переназначение психолога у записи

## Ручка

```http
POST /appointments/{appointment_id}/reassign
```

Тело запроса не требуется. Новый психолог определяется по текущему
авторизованному пользователю.

## Кто может выполнить переназначение

Пользователь должен:

- быть авторизован;
- иметь роль психолога;
- иметь профиль психолога.

## Когда переназначение разрешено

Запись должна существовать, иметь статус `awaiting` и быть назначена на будущее
время. Новый психолог должен быть доступен в это время и не иметь другой
активной записи на тот же слот.

Повторный запрос от уже назначенного психолога ничего не изменяет и возвращает
текущую запись.

## Что меняется

У записи обновляются `psychologist_id` и `last_change_time`. Время, формат,
место, комментарии и остальные согласованные условия сохраняются.

Все ожидающие запросы переноса этой записи получают статус `rejected`, время
ответа и комментарий о переназначении. Изменения выполняются в одной
транзакции.

## Ответы

- `200` — психолог назначен или уже был назначен;
- `401` — нет корректной авторизации;
- `403` — у пользователя нет роли психолога или профиля психолога;
- `404` — запись не найдена;
- `409` — запись завершена, отменена, уже началась либо новый психолог занят
  или недоступен.

Статическая спецификация обновляется командой:

```powershell
python scripts/export_openapi.py
```
